# Отчёт о приватности vladossVPN

**Версия документа:** 1.0 (2026-11-25)
**Связанный экран:** «Приватность» (`PRIVACY_REPORT_ENABLED`)
**Принцип:** каждое утверждение ниже проверяется по исходному коду, а экран собирает отчёт из тех же флагов, что управляют поведением.

## 1. Что хранится на устройстве

| Данные | Где | Уходит с устройства |
|---|---|---|
| Профили, подписки, настройки | приватное хранилище приложения | нет |
| Пароли профилей, идентификатор устройства | зашифрованное хранилище (AES-256) | нет |
| Журнал приложения | приватная папка приложения, адреса и ключи маскируются | нет |
| Файлы сбоев | приватная папка приложения | нет, автоматической отправки не существует |

## 2. Какие запросы делает приложение

| Зачем | Куда | Когда |
|---|---|---|
| Обновление подписки | адрес подписки, который вы добавили | по расписанию и вручную |
| Проверка связи | публичные проверочные адреса | при проверке подключения |
| Проверка обновлений | GitHub Releases | если самопроверка обновлений включена |
| Правила маршрутизации | публичные наборы правил | если включены geo-правила |

Реальные адреса подписок и профилей никогда не попадают в отчёт, журнал поддержки или экспортируемый текст.

## 3. Идентификаторы

- Приложение формирует производный идентификатор из системного идентификатора устройства с солью приложения. Исходный системный идентификатор не передаётся.
- Идентификатор и модель устройства передаются панели подписки **только** при явном согласии в настройках. По умолчанию согласие выключено.
- Согласие можно отозвать в любой момент; после отзыва метаданные не отправляются.

## 4. Телеметрия и сбои

- В сборку не включены Firebase, Crashlytics, Sentry, рекламные и аналитические SDK.
- Отчёты о сбоях не отправляются автоматически. Файл остаётся на устройстве, пока вы сами его не выгрузите.
- Приложение не содержит встроенных подписок и серверов: адреса задаёте вы.

## 5. Разрешения и зачем они

| Разрешение | Зачем |
|---|---|
| Интернет | VPN, обновление подписок |
| Состояние сети | замечать смену Wi-Fi и LTE |
| Работа в фоне | держать VPN включённым |
| Уведомления | показывать состояние VPN |
| Автозапуск | возвращать VPN после перезагрузки, если включено |
| Установка обновлений | установить скачанный APK вручную |

## 6. Чего приложение не делает

- Не отправляет журналы и файлы сбоев без вашего действия.
- Не использует рекламные идентификаторы и стороннюю аналитику.
- Не передаёт адреса ваших серверов и название подписки в отчёт.
- Не включает телеметрию по умолчанию.

## 7. Как проверить

1. Откройте «Приватность» — отчёт собирается из текущих флагов и настроек.
2. Включите и выключите согласие на метаданные устройства: строки про идентификатор должны измениться.
3. Скопируйте отчёт: он не должен содержать адресов, ключей и имён подписок.

Если утверждение в этом документе расходится с кодом — это ошибка, и приоритет у кода. Экран и этот документ обновляются в одном изменении.
