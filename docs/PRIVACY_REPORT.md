# Отчёт о приватности vladossVPN

**Версия документа:** 1.1 (2026-11-26)
**Статус:** отчёт собирается из реальных переключателей; экран «Приватность» ещё не включён (`PRIVACY_REPORT_ENABLED = false`).
**Принцип:** каждое утверждение ниже проверяется по исходному коду, а отчёт строится из тех же значений, что управляют поведением.

> Экран «Приватность» появится в следующей волне. В этой сборке флага нет, поэтому отчёт нельзя открыть из интерфейса. Код отчёта и единственный маппер реальных настроек (`AndroidPrivacyInputsProvider`) уже готовы и протестированы; документ описывает то, что будет показано, и не выдаёт будущий экран за существующий.

## 1. Что хранится на устройстве

| Данные | Где | Уходит с устройства |
|---|---|---|
| Профили, подписки, настройки | приватное хранилище приложения | нет |
| Сохранённые профили, включая пароли, и производный идентификатор | зашифрованное хранилище (AES-256) | нет |
| Журнал приложения | приватная папка приложения, адреса и ключи маскируются | нет |
| Файлы сбоев | приватная папка приложения | нет, автоматической отправки не существует |

## 2. Какие запросы делает приложение

| Зачем | Куда | Когда |
|---|---|---|
| Обновление подписки | адрес подписки, который вы добавили | по расписанию и вручную |
| Проверка связи | публичные проверочные адреса | при проверке подключения |
| Проверка обновлений | GitHub Releases | только в сборках с `ENABLE_SELF_UPDATE = true` |
| Правила маршрутизации | GitHub (наборы правил) | только при пресете «Обход локальной сети и сайтов РФ» (`BYPASS_RU`) |

Реальные адреса подписок и профилей никогда не попадают в отчёт, журнал поддержки или экспортируемый текст.

## 3. Идентификаторы

- Приложение формирует производный идентификатор из системного идентификатора устройства с солью приложения. Исходный системный идентификатор не передаётся.
- Производный идентификатор и модель устройства передаются панели подписки **только** при явном согласии в настройках. По умолчанию согласие выключено.
- Отдельного переключателя «HWID» нет: отправка управляется только согласием, поэтому конфигурация «идентификатор включён без согласия» невозможна.
- Согласие можно отозвать в любой момент; после отзыва метаданные не отправляются.

## 4. Телеметрия и сбои

- В сборку не включены Firebase, Crashlytics, Sentry, рекламные и аналитические SDK.
- Отчёты о сбоях не отправляются автоматически. Файл остаётся на устройстве, пока вы сами его не выгрузите.
- Приложение не содержит встроенных подписок и серверов: адреса задаёте вы.

## 5. Разрешения и зачем они

| Разрешение | Зачем |
|---|---|
| Интернет | VPN, обновление подписок |
| Состояние сети | замечать смену Wi-Fi и LTE |
| Изменение состояния сети | переподключать туннель при смене сети |
| Работа в фоне | держать VPN включённым |
| Специальный тип фоновой службы | обязательное объявление VPN-службы на современных Android |
| Не давать устройству засыпать | не обрывать туннель во время работы |
| Уведомления | показывать состояние VPN |
| Исключение из экономии батареи | приложение может предложить отключить оптимизацию; решение за вами. Только в direct-сборке, в play-сборке разрешения нет |
| Автозапуск | возвращать VPN после перезагрузки, если включено |
| Установка обновлений | установить скачанный APK вручную. Только в direct-сборке, в play-сборке обновления приходят из магазина |

## 6. Чего приложение не делает

- Не отправляет журналы и файлы сбоев без вашего действия.
- Не использует рекламные идентификаторы и стороннюю аналитику.
- Не передаёт адреса ваших серверов и название подписки в отчёт.
- Не включает телеметрию по умолчанию.

## 7. Как проверить (после включения экрана)

1. Когда флаг `PRIVACY_REPORT_ENABLED` будет включён, откройте «Приватность»: отчёт соберётся через `AndroidPrivacyInputsProvider`.
2. Включите и выключите согласие на метаданные устройства: строки про идентификатор должны измениться.
3. Скопируйте отчёт: он не должен содержать адресов, ключей и имён подписок.

До появления экрана те же утверждения проверяются юнит-тестами `PrivacyReportBuilderTest` и чтением `AndroidPrivacyInputs.kt`.

Если утверждение в этом документе расходится с кодом — это ошибка, и приоритет у кода. Экран и этот документ обновляются в одном изменении.
