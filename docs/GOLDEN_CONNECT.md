## 0. Как пользоваться этим файлом

1. Симптом → раздел **§8 Симптомы → действия**.
2. Сверить текущий generated JSON и логи с **§2–§5**.
3. Катить только изменения, возвращающие эталон; не смешивать с новыми фичами.
4. После фикса прогнать **§7 Acceptance** на device.
5. Обновлять этот файл только по правилам **§11**.
